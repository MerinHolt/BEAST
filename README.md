# Outplay™ — витрина сборки

Открытая часть проекта: готовые файлы сборки, которые тянет установщик Outplay™.

- `site/manifest.json` — каталог модов (id, версии, размеры, зависимости)
- `site/update.json` — версия сборки, зеркала и ссылки сообщества
- `site/mods/<id>.zip` — payload мода, скачивается по мере выбора
- `site/mods/<id>/preview.jpg` — превью
- `site/index.html` — веб-версия каталога

Исходники и инструменты сборки — в приватном репозитории проекта.
